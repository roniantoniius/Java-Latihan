About course
Web server programming Java is open to everyone at the University of Helsinki free web server programming basics instructive web course. The course introduces you to the basic ideas of web applications and their implementing. Taking the course requires programming the courses fundamentals (TKT10002), Programming Advanced (TKT10003) and Basics of databases (TKT10004) knowledge and Java programming language skills or enthusiasm to learn it during the course.
